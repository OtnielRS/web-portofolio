# Technology icons

SVG logos are from Devicon v2.17.0: https://github.com/devicons/devicon/tree/v2.17.0/icons

Source pattern: `icons/{technology}/{technology}-original.svg`, falling back to `-plain.svg` when unavailable. React Native uses React's icon. Logos are served locally; monochrome logos invert in dark mode. Original SVGs are unmodified.

Gemini and OpenAI logos are from Lobe Icons `@lobehub/icons-static-svg` v1.106.0, retrieved from `https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@1.106.0/icons/{gemini-color,openai}.svg`. Source: https://github.com/lobehub/lobe-icons. The MIT license is included in LICENSE-lobe-icons.txt.
